# ✋ Hand Gesture Detection

This is my first step into the world of project building!

I created a simple **Hand Gesture & Finger Detection** project using Python. It uses my webcam to detect hands in real time and identify fingers using computer vision.

### 🛠️ Technologies Used
- Python
- OpenCV
- MediaPipe

### ▶️ How to Run
1. Clone this repository.
2. Install the required libraries:
   ```bash
   pip install opencv-python mediapipe
   ```
3. Run the project:
   ```bash
   python main.py
   ```
